# 全台房價預測模型 Taiwan Housing Price Prediction Model

> 公司內部專案，程式碼因保密協議不便公開，此 PDF 為方法論與結果的完整說明。

## 專案簡介
以內政部實價登錄資料為基礎，建立每季可更新的全台房價預測系統。
涵蓋 2012–2026 Q1 共 55 季、逾 100 萬筆交易資料，
產出各縣市／行政區／屋齡區間／房屋類型的季度房價分佈指標，
並串接公司前端系統上線供使用者查詢。

## 技術棧
- **語言**：Python
- **資料處理**：Pandas, NumPy
- **空間分析**：GeoPandas, Geopy
- **建模**：LightGBM, scikit-learn
- **可解釋性**：SHAP
- **視覺化**：Matplotlib, Seaborn

## 核心方法
- 資料清洗：排除親友交易、非住宅類型、IQR 行政區分層離群值過濾
- 特徵工程：GIS 空間距離特徵（捷運／台鐵／高鐵／商圈）、K-means 局部地段聚類均價、路段交易量
- 建模：LightGBM + 10-Fold Cross Validation
- 可解釋性：SHAP 特徵重要性分析
- 後處理：殘差分析排除極端誤差樣本後計算季度房價分佈
